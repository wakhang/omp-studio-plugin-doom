# DOOM

OMP Studio 대화창에서 DOOM(1993, 셰어웨어 에피소드 1)을 플레이합니다.

## 사용법
- 대화창에 **"둠 하자"** → 에이전트가 `play_doom` 도구를 불러 답변 안에 게임을 띄웁니다. **▶ DOOM 시작**을 누르세요.
- 토큰 없이 바로: 입력창의 **👹 버튼** 또는 명령 팔레트 **DOOM 플레이** → 창으로 열립니다.
- 예전 대화의 게임은 자동으로 실행되지 않습니다(버튼을 눌러야 시작).

## 조작
| 키 | 동작 |
| --- | --- |
| 방향키 | 이동·회전 |
| Ctrl / 왼쪽 클릭 | 발사 |
| Space | 문 열기·사용 |
| `,` `.` | 옆걸음 |
| Shift | 달리기 |
| 1–7 | 무기 |
| Esc / Enter | 메뉴 / 확인 |

게임을 먼저 클릭해야 키가 들어갑니다. 다른 곳을 클릭하면 일시정지되고, 게임 안에서 누른 키는 앱 단축키로 넘어가지 않습니다.

## 제약
- 소리 없음, 저장 없음, 셰어웨어 에피소드 1만.
